How to find the mode command

1. Subscribe to every characteristic that supports Notify or Indicate.
2. Change the mode by touch on the earbuds.
3. Watch which bytes arrive in the log — that is the encoding your model uses.
4. Replay those exact bytes with Send.

Some firmwares need a handshake frame first (often a read of a "protocol version" characteristic). If writes disconnect the earbuds, try Write With Response instead.
